# Online Retail ETL Project — Progress Starter Pack

## Files
- `01_Online_Retail_Initial_EDA.ipynb` — extraction and initial EDA notebook.
- `requirements.txt` — Python packages used in the notebook.
- `PROGRESS_UPDATE_TODAY.md` — honest progress update draft.
- `data/raw/` — place the original downloaded Excel workbook here.
- `data/processed/` — later phase: cleaned/transformed outputs.
- `outputs/` — generated EDA summaries and charts may be saved here.

## Start here
1. Download `Online Retail.xlsx` from https://archive.ics.uci.edu/dataset/352/online+retail
2. Place the file at `data/raw/Online Retail.xlsx`.
3. Install packages: `pip install -r requirements.txt`
4. Open `01_Online_Retail_Initial_EDA.ipynb` in Jupyter Notebook, JupyterLab, or VS Code.
5. Run the notebook from top to bottom and review the real outputs before presenting them.

The raw workbook should remain unchanged. The notebook currently performs initial exploration and does not claim that the data is already cleaned or loaded into a database.
